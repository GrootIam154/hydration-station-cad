# Hydration Station CAD

SolidWorks parts and the station layout assembly for the Hydration Station project.

The CAD folder contains the funnel, sanitation box bottom plate, slider tray, three piping holder variants, door panel, frame and station assembly with its referenced part files.

## Opening the assembly

Download the repository and open `CAD/HydrationStandV2.SLDASM` in SolidWorks. Keep all CAD files in the same folder so the assembly can find its six referenced parts.

## Model notes

The station assembly uses simplified block models for several components. It is not a detailed sanitation box assembly. The piping holder files are separate design variants; compare them before selecting a version for fabrication.
