# Hydration Station CAD

Downloadable SolidWorks part files for the Hydration Station project.

## Download all files

[Download all SolidWorks files (ZIP)](https://github.com/GrootIam154/hydration-station-cad/archive/refs/heads/main.zip)

Extract the ZIP, then open any `.SLDPRT` file from the `CAD` folder in SolidWorks.
